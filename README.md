# Calculus Notebook

A handwritten-style interactive notebook that teaches calculus from foundations to advanced topics with sketches, step-by-step examples, and practice problems.

## 📥 Download APK

You can download and install the latest Android APK directly from the GitHub Releases page:

## ✨ Features

- **Interactive Calculus Lessons:** Learn everything from Limits and Derivatives to Integrals and Taylor Series.
- **Digital Scratchpad:** Sketch out your calculus diagrams, function curves, and math notes directly within the notebook entries using the built-in digital canvas.
- **Powerful Search:** Find terms, equations, definitions, and worked examples instantly with live LaTeX previews.
- **Progress Tracking:** Mark topics as completed and track your learning journey through the interactive index.
- **Hand-Drawn Aesthetic:** Enjoy a beautiful, custom handwriting style and notebook design.

## 🛠️ Built With

- **Kotlin**
- **Jetpack Compose** (Material Design 3)
- **Room Database** (Local Progress & Data Persistence)

## 🚀 Build Instructions

To build the project locally using Gradle:

```bash
./gradlew assembleDebug
```

The compiled APK will be generated and available in the `app/build/outputs/apk/debug/` directory.
